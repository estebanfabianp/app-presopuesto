# Constantes del Sistema - Inicio Rápido

## Vista involucrada

```text
src/views/constante.py
```

## Objetivo

Administrar constantes del sistema desde la interfaz Flet.

## Acciones soportadas

- listar constantes,
- buscar por nombre,
- filtrar por categoría,
- crear,
- editar,
- eliminar de forma lógica.

## Tipos de dato soportados

- `STRING`
- `INTEGER`
- `DECIMAL`
- `BOOLEAN`
- `JSON`
- `DATE`

## Recomendaciones

- usa nombres únicos y consistentes,
- valida el tipo antes de guardar,
- evita dejar trazas de depuración permanentes en la vista.
