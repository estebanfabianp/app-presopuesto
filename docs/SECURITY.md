# Política de Seguridad

La seguridad de los usuarios y sus datos es una prioridad.

## Reporte de Vulnerabilidades

Si encuentras una vulnerabilidad o problema de seguridad, por favor:

1. No la divulgues públicamente.
2. Envía un correo a: estebanfabianp@gmail.com con los detalles.
3. Proporciona información suficiente para reproducir el problema.
4. También puedes abrir un issue confidencial en el repositorio si está habilitado.

Nos comprometemos a investigar y resolver los problemas de seguridad lo antes posible y a mantenerte informado sobre el estado del reporte.

## Buenas Prácticas

- Usa contraseñas seguras y únicas.
- No compartas tus credenciales.
- Mantén tu entorno y dependencias actualizadas.
- El proyecto utiliza hash seguro para contraseñas (bcrypt), autenticación JWT y validación de entradas.
- Se recomienda el uso de variables de entorno para datos sensibles.
- El sistema implementa control de acceso por roles y auditoría de acciones críticas y logs de actividad.
- Exportación segura de datos y reportes.
- Pruebas de seguridad y revisiones periódicas del código y dependencias.

Gracias por ayudar a mantener el proyecto seguro.
