# Código de Conducta

Compromiso con un ambiente abierto, acogedor y respetuoso.

## Normas Básicas

- Amabilidad, respeto, inclusión y diversidad.
- No se tolera acoso ni discriminación.
- Críticas constructivas y colaboración de buena fe.
- Ayuda a nuevos colaboradores.

## Reporte de Incidentes

- Reportar a estebanfabianp@gmail.com o abrir issue confidencial.

Este código aplica a todos los canales oficiales del proyecto, incluyendo issues, pull requests, foros, módulos de notificaciones y auditoría, y cualquier otro espacio gestionado por el equipo.
