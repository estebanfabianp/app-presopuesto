# Política de Seguridad

La seguridad de los usuarios y sus datos es una prioridad.

## Reporte de Vulnerabilidades

Si encuentras una vulnerabilidad o problema de seguridad, por favor:

1. No la divulgues públicamente.
2. Envía un correo a: estebanfabianp@gmail.com con los detalles.
3. Proporciona información suficiente para reproducir el problema.

Nos comprometemos a investigar y resolver los problemas de seguridad lo antes posible.

## Buenas Prácticas

- Usa contraseñas seguras y únicas.
- No compartas tus credenciales.
- Mantén tu entorno y dependencias actualizadas.
- El proyecto utiliza hash seguro para contraseñas y validación de entradas.

Gracias por ayudar a mantener el proyecto seguro.
