# Guía de Usuario — Sistema de Gestión de Presupuestos

Esta guía te ayudará a comenzar a utilizar la aplicación para gestionar tus finanzas personales.

---

## 1. Instalación y Primeros Pasos

Sigue los pasos de instalación descritos en el [README.md](README.md) para preparar el entorno, configurar variables de entorno, ejecutar migraciones y lanzar la API. Puedes cargar datos de prueba para explorar las funcionalidades.

---

## 2. Acceso y Autenticación

- Regístrate como usuario nuevo o inicia sesión si ya tienes una cuenta.
- La autenticación es necesaria para acceder a tus datos personales y proteger tu información financiera.
- El sistema utiliza autenticación JWT para mayor seguridad.
- Puedes cerrar sesión desde la aplicación para proteger tu cuenta.

---

## 3. Funcionalidades Principales

### a) Registro de Movimientos

- Ingresa ingresos y gastos desde el formulario correspondiente.
- Asocia cada movimiento a una cuenta y una categoría.
- Puedes cargar extractos bancarios para registrar múltiples movimientos automáticamente.
- Soporte para movimientos recurrentes y cuotas.
- Visualiza el historial y detalles de cada movimiento.

### b) Gestión de Presupuestos

- Crea presupuestos mensuales, anuales o por categoría.
- Consulta el estado de tus presupuestos y compara el gasto real con lo planificado.
- Recibe alertas cuando te acerques o superes el límite de un presupuesto.

### c) Control de Deudas y Préstamos

- Registra préstamos, tarjetas de crédito y deudas financiadas.
- Lleva el control de pagos, cuotas pendientes y fechas de vencimiento.
- Visualiza el avance de pagos y el saldo pendiente.

### d) Inversiones y Activos

- Añade inversiones en acciones, fondos y otros activos.
- Consulta el valor actual y la rentabilidad de tu portafolio.
- Gestiona activos físicos y su depreciación.

### e) Reportes y Visualización

- Accede a reportes visuales: flujo de caja, resumen mensual, gastos por categoría, desempeño del presupuesto, etc.
- Identifica patrones de consumo y oportunidades de ahorro.
- Exporta reportes en diferentes formatos (ej. Excel, PDF).

### f) Notificaciones y Configuración

- Recibe notificaciones sobre vencimientos, alertas de presupuesto y recomendaciones.
- Personaliza tus preferencias y configuración de usuario.

---

## 4. Automatización e Inteligencia

- La aplicación categoriza automáticamente tus movimientos usando reglas e inteligencia artificial.
- Recibe sugerencias para optimizar tus gastos y estrategias de pago (por ejemplo, método de la bola de nieve).
- El sistema aprende de tus hábitos para mejorar la experiencia y las recomendaciones.

---

## 5. Consejos de Seguridad

- Utiliza contraseñas seguras y no las compartas.
- Cierra sesión después de usar la aplicación en dispositivos compartidos.
- Mantén tu aplicación y dependencias actualizadas.
- Consulta la [política de seguridad](SECURITY.md) para más recomendaciones.
