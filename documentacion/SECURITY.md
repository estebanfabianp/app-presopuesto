# Política de Seguridad

La seguridad de los usuarios y sus datos es una prioridad.

## Reporte de Vulnerabilidades

- No divulgar públicamente.
- Contactar por correo: estebanfabianp@gmail.com
- Abrir issue confidencial si está habilitado.

## Buenas Prácticas

- Contraseñas seguras (bcrypt), autenticación JWT, validación robusta.
- Uso de variables de entorno para datos sensibles.
- Control de acceso por roles y auditoría.
- Exportación segura de datos y reportes.
- Pruebas de seguridad y revisiones periódicas del código y dependencias.

Gracias por ayudar a mantener el proyecto seguro.
